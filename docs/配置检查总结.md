## 🔍 问题分析

### 错误信息

```
Cannot stop Docker Compose application. Reason: Max retries reached: 
Error invoking remote method 'containers.composeBulkAction__wrapped': 
Error: An object could not be cloned.
```

### 根本原因

**不是配置问题**，而是：

1. **Docker Desktop GUI 的 bug**
   - Docker Desktop 的 Electron 应用与 Docker daemon 通信失败
   - 这是 Docker Desktop 的内部错误

2. **操作方式问题**
   - 同时使用 Docker Desktop GUI 和命令行
   - 同时操作多个 Docker Compose 项目
   - 导致 Docker Desktop 无法正确处理

---

## ✅ 解决方案

### 1. 使用统一启动脚本（推荐）

```bash
cd /Users/Daniel/Documents/GitHub/AAM

# 启动所有服务（按顺序）
./scripts/start-all-services.sh all

# 停止所有服务
./scripts/start-all-services.sh cleanup
```

**优点**:
- ✅ 避免 Docker Desktop GUI 的 bug
- ✅ 按顺序启动服务
- ✅ 更好的错误控制

### 2. 使用命令行操作

**避免使用 Docker Desktop GUI**，全部使用命令行：

```bash
# 启动 aam-service
cd aam-service
docker-compose -f docker-compose.dev.yml up -d

# 等待就绪
sleep 30

# 启动 aam-admin
cd ../aam-admin
docker-compose -f docker-compose.dev.yml up -d
```

### 3. 按顺序操作

**重要**: 不要同时启动多个服务，按顺序操作：

1. 先启动 aam-service
2. 等待 aam-service 完全就绪（至少 30 秒）
3. 再启动 aam-admin
