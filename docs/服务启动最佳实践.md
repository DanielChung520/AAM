# AAM 系统服务启动最佳实践

**创建日期**: 2025-01-14  
**目的**: 避免 Docker Compose 错误，确保服务稳定启动

---

## 🎯 核心原则

### 1. 使用命令行，避免 Docker Desktop GUI

**原因**:
- Docker Desktop GUI 可能存在 bug
- 命令行提供更好的错误控制
- 可以按顺序执行操作

### 2. 按顺序启动服务

**启动顺序**:
1. aam-service（包括所有依赖服务）
2. 等待 aam-service 完全就绪
3. aam-admin

### 3. 使用统一启动脚本

**推荐使用**: `./scripts/start-all-services.sh`

---

## 🚀 标准启动流程

### 方法 1: 使用统一脚本（推荐）

```bash
cd /Users/Daniel/Documents/GitHub/AAM

# 1. 检查 Docker 状态
docker info

# 2. 启动所有服务（按顺序）
./scripts/start-all-services.sh all
```

### 方法 2: 手动启动（如果需要）

```bash
# 1. 启动 aam-service
cd aam-service
docker-compose -f docker-compose.dev.yml up -d

# 2. 等待服务就绪（至少 30 秒）
sleep 30

# 3. 验证 aam-service
docker-compose -f docker-compose.dev.yml ps

# 4. 启动 aam-admin
cd ../aam-admin
docker-compose -f docker-compose.dev.yml up -d

# 5. 验证 aam-admin
docker-compose -f docker-compose.dev.yml ps
```

---

## 🛑 停止服务

### 使用统一脚本

```bash
./scripts/start-all-services.sh cleanup
```

### 手动停止

```bash
# 停止 aam-admin（先停止）
cd aam-admin
docker-compose -f docker-compose.dev.yml down

# 停止 aam-service
cd ../aam-service
docker-compose -f docker-compose.dev.yml down
```

---

## ⚠️ 避免的操作

### ❌ 不要做的

1. **不要同时使用 Docker Desktop GUI 和命令行**
   ```bash
   # ❌ 错误：在 GUI 中操作，同时在命令行操作
   ```

2. **不要同时启动多个 Docker Compose 项目**
   ```bash
   # ❌ 错误：同时运行
   docker-compose -f aam-service/docker-compose.dev.yml up -d &
   docker-compose -f aam-admin/docker-compose.dev.yml up -d &
   ```

3. **不要在 Docker Desktop 中手动操作容器**
   - 如果遇到错误，使用命令行清理

### ✅ 应该做的

1. **使用统一脚本**
   ```bash
   ./scripts/start-all-services.sh all
   ```

2. **按顺序操作**
   - 先启动 aam-service
   - 等待就绪后再启动 aam-admin

3. **使用命令行**
   - 避免 Docker Desktop GUI 的 bug

## 🐛 故障排查

### 如果启动失败

1. **检查 Docker 状态**
   ```bash
   docker info
   ```

2. **检查端口占用**
   ```bash
   lsof -i :8000 -i :8001 -i :8003 -i :5432 -i :5433
   ```

3. **清理并重新启动**
   ```bash
   ./scripts/start-all-services.sh cleanup
   sleep 10
   ./scripts/start-all-services.sh all
   ```

### 如果 Docker Desktop 错误

1. **使用命令行操作**
   - 避免 Docker Desktop GUI

2. **重启 Docker Desktop**
   ```bash
   killall Docker && open -a Docker
   sleep 90
   docker info
   ```
