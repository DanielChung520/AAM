## 📝 运行测试指南

### 后端测试

```bash
# 进入后端目录
cd backend

# 激活虚拟环境（如果使用）
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate  # Windows

# 运行所有测试
pytest

# 运行特定测试文件
pytest tests/test_security_routes.py

# 显示详细输出
pytest -v

# 显示覆盖率
pytest --cov=src --cov-report=html

# 使用测试脚本
./tests/run_tests.sh
```

### 前端测试

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 运行所有测试
npm test

# 运行测试（监听模式）
npm test -- --watch

# 运行测试 UI
npm run test:ui

# 生成覆盖率报告
npm run test:coverage
```
