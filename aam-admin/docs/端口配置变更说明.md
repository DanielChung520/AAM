## 🚀 使用新端口

### 启动后端服务

```bash
# Docker 方式
cd /Users/Daniel/Documents/GitHub/AAM/aam-admin
docker-compose -f docker-compose.dev.yml up admin-backend -d

# 本地方式
cd /Users/Daniel/Documents/GitHub/AAM/aam-admin/backend
source venv/bin/activate
uvicorn src.main:app --reload --host 0.0.0.0 --port 8003
```

### 访问地址

- **API 文档**: http://localhost:8003/docs
- **健康检查**: http://localhost:8003/health
- **API 端点**: http://localhost:8003/api/v1

---

## ⚠️ 注意事项

1. **环境变量**: 如果使用 `.env` 文件，需要更新 `API_PORT=8003`
2. **前端配置**: 如果使用环境变量，需要更新 `VITE_API_BASE_URL=http://localhost:8003`
3. **端口冲突**: 确保端口 8003 未被占用
