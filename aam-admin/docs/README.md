## 🚀 快速開始

### 開發者入門

1. **閱讀系統設計**
   - 先閱讀 [AAM 管理系統 - 系統設計規格](./AAM管理系統-SD.md)
   - 了解技術架構、功能架構和組件設計

2. **了解 UI/UX 設計**
   - 閱讀 [AAM 管理系統 - 頁面佈局設計](./AAM管理系統-頁面佈局設計.md)
   - 了解頁面佈局、導航結構和 UI 組件規範

3. **參考 AAM 服務文檔**
   - 如需了解 AAM 服務的 API 和安全認證，請參考 `../aam-service/docs/`
   - 特別是 [AAM 企業安全認證管理手冊](../aam-service/docs/AAM企業安全認證管理手冊.md)
