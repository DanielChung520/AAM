# 阶段三：版本管理与部署 (Version Management & Deployment)

## 目标

实现完整的版本管理和零中断部署功能，包括版本创建、存储、比较、部署历史、三种部署策略（蓝绿、滚动、金丝雀）以及自动健康检查和回滚机制。

## 预计时间

2-3 周

---

## 3.1 版本管理 (Version Management)

### 后端实现

#### 3.1.1 创建版本管理路由

- **文件**: `aam-admin/backend/src/api/routers/version.py`
- **任务**:
- 实现 `GET /api/v1/admin/versions` - 获取版本列表（支持分页、排序、过滤）
- 实现 `POST /api/v1/admin/versions` - 创建新版本（基于 Git Tag 或手动创建）
- 实现 `GET /api/v1/admin/versions/{version}` - 获取版本详情
- 实现 `GET /api/v1/admin/versions/{v1}/compare/{v2}` - 比较两个版本的配置差异
- 实现 `GET /api/v1/admin/versions/active` - 获取当前活动版本
- 实现 `DELETE /api/v1/admin/versions/{version}` - 删除版本（仅非活动版本）
