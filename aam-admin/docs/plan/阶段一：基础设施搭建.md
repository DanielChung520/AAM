# 阶段一：基础设施搭建 (Foundation Setup)

## 目标

建立项目基础架构、开发环境和核心基础设施，为后续功能开发奠定坚实基础。

## 前置条件

- 已阅读系统设计文档 (`aam-admin/docs/AAM管理系統-SD.md`)
- 已阅读页面布局设计文档 (`aam-admin/docs/AAM管理系統-頁面佈局設計.md`)
- 已确认前端开发规范 (`.cursor/rules/frontend-development-rule.mdc`)

## 注意事项

### 前端开发规范强制要求

1. **文件位置**: 所有文件必须放在规范指定的目录，禁止随意创建新目录
2. **深色模式**: 所有 UI 组件必须支持深色模式，使用主题变量而非硬编码颜色
3. **TypeScript**: 所有代码必须使用 TypeScript，禁止使用 `any` 类型（除非必要且需注释）
4. **组件结构**: 所有组件必须包含文件头注释（@purpose, @author, @createdAt, @lastModified）
5. **代码规范**: 所有代码必须通过 ESLint 和 Prettier 检查

### 后端开发规范要求

1. **代码规范**: 使用 Black 格式化代码，使用 isort 整理导入
2. **类型检查**: 使用 mypy 进行类型检查
3. **API 文档**: 使用 FastAPI 自动生成 OpenAPI 文档
4. **错误处理**: 实现统一的错误处理机制

### 数据库设计原则

1. **规范化**: 遵循数据库设计规范化原则
2. **索引**: 为常用查询字段添加索引
3. **审计**: 所有重要操作记录审计日志
4. **迁移**: 使用 Alembic 管理数据库迁移
