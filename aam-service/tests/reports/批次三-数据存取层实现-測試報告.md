## 🔍 技术亮点

### 1. Repository Pattern 实现
- 所有数据存取类实现对应的接口（`IKnowledgeStore`, `IPersonaStore`）
- 封装了所有数据库特定逻辑，业务逻辑层无需了解底层实现细节

### 2. 异步优先
- 所有数据库操作使用异步方法（`async def`）
- 使用 SQLAlchemy 2.0+ 异步语法
- 支持异步上下文管理器

### 3. 配置化设计
- 所有数据库连接参数从配置类加载
- 支持依赖注入，便于测试和替换实现

### 4. 向量化服务优化
- 模型懒加载，避免不必要的模型加载
- 支持批量向量化，提高性能
- 可配置的模型缓存目录

### 5. ChromaDB 混合搜索
- 向量相似度搜索 + 元数据过滤
- 距离转换为相似度分数
- 支持用户级别的知识检索

### 6. PostgreSQL JSONB 支持
- 使用 JSONB 字段存储字典数据（`style_tags`, `sentiment_history`）
- 正确处理字典的序列化/反序列化
- 支持 UPSERT 操作
