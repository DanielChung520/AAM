## 應用程序配置

| 參數名 | 預設值 | 說明 | 範例 |
|--------|--------|------|------|
| `APP_NAME` | `AAM Service` | 應用程序名稱 | `AAM Service` |
| `APP_VERSION` | `1.0.0` | 應用程序版本號 | `1.0.0` |
| `DEBUG` | `False` | 調試模式開關（True/False） | `True` |
| `LOG_LEVEL` | `INFO` | 日誌級別（DEBUG/INFO/WARNING/ERROR/CRITICAL） | `INFO` |

### 說明

- **DEBUG**: 開發環境建議設為 `True`，生產環境必須設為 `False`
- **LOG_LEVEL**: 日誌詳細程度，開發時可用 `DEBUG`，生產環境建議 `INFO` 或 `WARNING`

## API 配置

| 參數名 | 預設值 | 說明 | 範例 |
|--------|--------|------|------|
| `API_HOST` | `0.0.0.0` | API 服務監聽地址 | `0.0.0.0` |
| `API_PORT` | `8000` | API 服務端口 | `8000` |
| `API_KEY` | **必填** | API 認證密鑰（不能使用默認值） | `your-secret-api-key-123` |

### 說明

- **API_HOST**: 
  - `0.0.0.0` 表示監聽所有網絡接口
  - `127.0.0.1` 僅監聽本地回環接口
- **API_PORT**: 確保端口未被其他服務占用
- **API_KEY**: 
  - ⚠️ **必須設置且不能使用默認值** `your-secret-api-key-change-in-production`
  - 生產環境請使用強隨機密鑰
  - 用於 `POST /v1/mcp/enrich` 端點的認證（通過 `X-API-KEY` header）

| 參數名 | 預設值 | 說明 | 範例 |
|--------|--------|------|------|

## 安全配置

| 參數名 | 預設值 | 說明 | 範例 |
|--------|--------|------|------|
| `SECRET_KEY` | **必填** | JWT 和安全相關的密鑰（不能使用默認值） | `your-secret-key-123` |
| `ALGORITHM` | `HS256` | JWT 簽名算法 | `HS256` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `30` | 訪問令牌過期時間（分鐘） | `30` |
| `TOKEN_EXPIRE_HOURS` | `24` | Token 有效期（小時，用於 MCP Server） | `24` |
| `TOKEN_ISSUER` | `aam-agent` | Token 發行者標識 | `aam-agent` |
| `ENABLE_USER_ID_VALIDATION` | `true` | 是否啟用 user_id 驗證 | `true` |
| `ENTERPRISE_SECRET_KEY` | - | 企業 Secret Key（用於服務器間相互認證，如 SmartQ） | - |
| `ENABLE_ENTERPRISE_AUTH` | `false` | 是否啟用企業級認證（服務器間相互認證） | `false` |

### 說明

- **SECRET_KEY**: 
  - ⚠️ **必須設置且不能使用默認值** `your-secret-key-change-in-production`
  - 生產環境請使用強隨機密鑰（建議至少 32 字符）
  - 用於 JWT 令牌簽名和其他安全操作
- **ALGORITHM**: JWT 簽名算法，通常使用 `HS256`
- **ACCESS_TOKEN_EXPIRE_MINUTES**: 訪問令牌的有效期，單位為分鐘
- **TOKEN_EXPIRE_HOURS**: MCP Server 使用的 JWT token 有效期，單位為小時（默認 24 小時）
- **TOKEN_ISSUER**: Token 發行者標識，用於驗證 token 是否由 AAM 發行
- **ENABLE_USER_ID_VALIDATION**: 是否啟用 user_id 驗證，確保 token 中的 user_id 與請求的 user_id 匹配
- **ENTERPRISE_SECRET_KEY**: 
  - 企業 Secret Key，用於服務器間相互認證（如 SmartQ 與 AAM 之間）
  - 在部署前由雙方協議配置
  - 生產環境建議設置（如果啟用企業級認證）
  - 使用強隨機密鑰生成器生成（建議至少 32 字符）
- **ENABLE_ENTERPRISE_AUTH**: 
  - 是否啟用企業級認證（服務器間相互認證）
  - 如果啟用，MCP Server 調用時需要提供企業簽名（HMAC-SHA256）
  - 生產環境建議啟用，開發環境可關閉

## 快速開始

### 1. 複製範例文件

```bash
cd /Users/Daniel/Documents/GitHub/AAM/aam-service
cp .env.example .env
```

### 2. 編輯 .env 文件

必須設置以下參數：

```bash
# 必須設置的參數
API_KEY=your-secret-api-key-change-this
POSTGRES_PASSWORD=your-database-password
SECRET_KEY=your-secret-key-change-this
```

### 3. 完整範例配置

```bash
# ============================================
# 應用程序配置
# ============================================
APP_NAME=AAM Service
APP_VERSION=1.0.0
DEBUG=True
LOG_LEVEL=INFO

# ============================================
# API 配置
# ============================================
API_HOST=0.0.0.0
API_PORT=8000
API_KEY=your-secret-api-key-123  # ⚠️ 必須修改

# ============================================
# ChromaDB 配置
# ============================================
CHROMADB_HOST=chromadb
CHROMADB_PORT=8001
CHROMADB_COLLECTION_NAME=knowledge_assets

# ============================================
# PostgreSQL 配置
# ============================================
POSTGRES_HOST=postgres
POSTGRES_PORT=5432
POSTGRES_DB=aam_personas
POSTGRES_USER=aam_user
POSTGRES_PASSWORD=your-database-password  # ⚠️ 必須修改

# ============================================
# RabbitMQ 配置
# ============================================
RABBITMQ_HOST=rabbitmq
RABBITMQ_PORT=5672
RABBITMQ_USER=admin
RABBITMQ_PASSWORD=admin  # ⚠️ 生產環境請修改
RABBITMQ_QUEUE=aam.dialogue.archive
RABBITMQ_EXCHANGE=aam.exchange

# ============================================
# Redis 配置
# ============================================
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_DB=0

# ============================================
# AI 模型配置
# ============================================
MODEL_NAME=microsoft/DialoGPT-medium
MODEL_CACHE_DIR=./model_cache
EMBEDDING_MODEL=sentence-transformers/all-MiniLM-L6-v2
LORA_RANK=8
LORA_ALPHA=16
LORA_TARGET_MODULES=q_proj,v_proj

# ============================================
# 安全配置
# ============================================
SECRET_KEY=your-secret-key-123  # ⚠️ 必須修改
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30

# MCP Server Token 配置
TOKEN_EXPIRE_HOURS=24
TOKEN_ISSUER=aam-agent
ENABLE_USER_ID_VALIDATION=true

# 企業級認證配置（服務器間相互認證，如 SmartQ）
ENTERPRISE_SECRET_KEY=your-enterprise-secret-key-change-this  # 與 SmartQ 協議的 Secret Key
ENABLE_ENTERPRISE_AUTH=false  # 開發環境可關閉，生產環境建議啟用
```

## ⚠️ 重要注意事項

### 必須設置的參數

以下參數**必須設置**，否則應用程序無法啟動：

1. **API_KEY** - API 認證密鑰
2. **POSTGRES_PASSWORD** - PostgreSQL 數據庫密碼
3. **SECRET_KEY** - 安全密鑰

### 安全建議

1. **生產環境**：
   - 使用強隨機密鑰生成器生成 `API_KEY` 和 `SECRET_KEY`
   - 修改所有默認密碼（RabbitMQ、PostgreSQL 等）
   - 將 `DEBUG` 設為 `False`
   - 將 `LOG_LEVEL` 設為 `INFO` 或 `WARNING`

2. **開發環境**：
   - 可以使用較簡單的密鑰便於測試
   - `DEBUG` 可設為 `True` 以便調試
   - `LOG_LEVEL` 可設為 `DEBUG` 查看詳細日誌

3. **文件安全**：
   - ⚠️ **不要將 `.env` 文件提交到 Git**
   - `.env` 文件通常已在 `.gitignore` 中
   - 使用 `.env.example` 作為範例模板
