## 🔍 问题分析

### 问题 1: 模型响应时间过长

**问题描述**:
- deepseek-r1:8b 模型响应时间超过 240 秒
- 导致 NER、KT、个性分析全部超时

**可能原因**:
1. 模型本身需要较长的推理时间（reasoning 过程）
2. Prompt 复杂度过高
3. 系统资源限制（CPU/内存）
4. 超时设置过短（240秒可能不够）

**影响**:
- 语义分析功能无法正常工作
- 三元组分类标签无法验证
- 知识提取返回空结果

**建议解决方案**:
1. 增加超时设置（在 `.env` 中设置 `MODEL_TIMEOUT=600` 或更长）
2. 优化 Prompt 长度和复杂度
3. 考虑使用更小的模型进行快速测试
4. 使用 Mock 模型进行单元测试

### 问题 2: JSON 解析错误

**问题描述**:
- 在验证知识存储时，`triples_json` 可能为空字符串，导致 JSON 解析失败

**可能原因**:
- 语义分析失败，返回空结果
- 错误处理未正确处理空字符串情况

**建议解决方案**:
- 在验证代码中添加空字符串检查
- 改进错误处理逻辑
