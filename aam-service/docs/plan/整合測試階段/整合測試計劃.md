## 🏗️ 系统集成架构

### 集成点识别

```
┌─────────────────────────────────────────────────────────┐
│                    AAM Service                           │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐ │
│  │   API Layer  │  │  Service     │  │  AI Models   │ │
│  │  (FastAPI)   │  │  Layer       │  │  (Eb-MM/LC)  │ │
│  └──────┬───────┘  └──────┬───────┘  └──────┬───────┘ │
└─────────┼──────────────────┼──────────────────┼──────────┘
          │                  │                  │
          │                  │                  │
    ┌─────▼──────┐    ┌─────▼──────┐    ┌─────▼──────┐
    │  SmartQ    │    │  RabbitMQ   │    │  Ollama/   │
    │  (REST)    │    │  (AMQP)     │    │  vLLM/     │
    └────────────┘    └─────────────┘    │  OpenAI    │
                                          └────────────┘
          │                  │                  │
    ┌─────▼──────┐    ┌─────▼──────┐
    │  ChromaDB  │    │ PostgreSQL  │
    │  (Vector)  │    │ (Persona)   │
    └────────────┘    └─────────────┘
```

### 关键集成点

1. **SmartQ ↔ AAM Service**
   - 协议: REST API (POST /v1/mcp/enrich)
   - 数据格式: MCP (Model Context Protocol)
   - 认证: API Key

2. **AAM Service ↔ RabbitMQ**
   - 协议: AMQP
   - 用途: 异步对话归档
   - 队列: `dialogue_archive_queue`

3. **AAM Service ↔ ChromaDB**
   - 协议: HTTP API / Python Client
   - 用途: 知识库存储和检索
   - 操作: 向量搜索、元数据过滤

4. **AAM Service ↔ PostgreSQL**
   - 协议: SQL (asyncpg)
   - 用途: 用户画像存储
   - 操作: CRUD 操作

5. **AAM Service ↔ 模型服务**
   - Ollama: HTTP API (localhost:11434)
   - vLLM: OpenAI 兼容 API
   - OpenAI: REST API
   - Anthropic: REST API

5. [ ] CPU 使用测试

**实现方式**:
```python
# tests/performance/test_api_performance.py
@pytest.mark.performance
class TestAPIPerformance:
    """API 性能测试"""
    
    async def test_enrich_api_response_time(self, client):
        """测试 enrich API 响应时间"""
        import time
        
        times = []
        for _ in range(100):
            start = time.time()
            response = client.post("/v1/mcp/enrich", ...)
            elapsed = time.time() - start
            times.append(elapsed)
            assert response.status_code == 200
        
        # 计算统计信息
        p50 = np.percentile(times, 50)
        p95 = np.percentile(times, 95)
        p99 = np.percentile(times, 99)
        
        assert p95 < 0.5  # P95 < 500ms
        assert p99 < 1.0  # P99 < 1000ms
    
    async def test_concurrent_requests(self, client):
        """测试并发请求处理能力"""
        import asyncio
        
        async def make_request():
            response = client.post("/v1/mcp/enrich", ...)
            return response.status_code == 200
        
        # 并发 100 个请求
        tasks = [make_request() for _ in range(100)]
        results = await asyncio.gather(*tasks)
        
        success_rate = sum(results) / len(results)
        assert success_rate > 0.95  # 95% 成功率
```

```python
# tests/stress/test_high_load.py
@pytest.mark.stress
class TestHighLoad:
    """高负载压力测试"""
    
    async def test_gradual_load_increase(self, client):
        """测试逐步增加负载"""
        import asyncio
        
        load_levels = [10, 50, 100, 200, 500]
        for load in load_levels:
            # 发送 load 个并发请求
            tasks = [make_request() for _ in range(load)]
            results = await asyncio.gather(*tasks, return_exceptions=True)
            
            # 计算成功率
            success = sum(1 for r in results if not isinstance(r, Exception))
            success_rate = success / len(results)
            
            print(f"Load: {load}, Success Rate: {success_rate}")
            assert success_rate > 0.9  # 90% 成功率
```
