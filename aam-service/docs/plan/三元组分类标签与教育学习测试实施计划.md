# 
三元组分类标签与教育学习测试实施计划
## 目标

1. 实现三元组分类标签功能（AI自动分类 + 预定义分类映射）
2. 创建教育学习咨询测试对话场景
3. 执行对话归档测试
4. 验证ChromaDB和PostgreSQL中的数据存储

---

## 阶段一：扩展三元组模型支持分类标签

### 1.1 定义预定义分类列表

**文件**: `aam-service/src/models/domain/triple_categories.py` (新建)

- 定义预定义分类常量：技术、业务、人物关系、时间关系、教育、医疗、金融等
- 提供分类映射函数，将AI分类结果映射到预定义分类

### 1.2 扩展KnowledgeTriple模型

**文件**: `aam-service/src/models/api/mcp.py`

- 在`KnowledgeTriple`模型中添加`category: Optional[str]`字段
- 添加`ai_category: Optional[str]`字段（存储AI原始分类）

### 1.3 扩展KnowledgeAsset模型

**文件**: `aam-service/src/models/domain/database.py`

- 在`KnowledgeAsset.to_chromadb_metadata()`中添加`triple_categories`字段
- 从三元组JSON中提取分类信息并存储到metadata

## 阶段二：实现AI自动分类功能

### 2.1 创建三元组分类服务

**文件**: `aam-service/src/infrastructure/ai/triple_classifier.py` (新建)

- 实现`classify_triples()`方法，调用AI模型对三元组进行分类
- 实现`map_to_predefined_category()`方法，将AI分类映射到预定义分类
- 返回分类后的三元组列表（包含category字段）

### 2.2 修改知识提取流程

**文件**: `aam-service/src/infrastructure/ai/unified_model_service.py`

- 在`extract_knowledge()`方法中，提取三元组后调用分类服务
- 将分类后的三元组（包含category）序列化为JSON存储

**文件**: `aam-service/src/infrastructure/ai/eb_mm_analysis_model.py`

- 同样在`extract_knowledge()`中添加分类逻辑

**文件**: `aam-service/src/infrastructure/ai/ollama_analysis_model.py`

- 同样在`extract_knowledge()`中添加分类逻辑

## 技术细节

### 三元组分类标签格式

```json
{
  "subject": "Python",
  "predicate": "用于",
  "object": "Web 开发",
  "category": "技术",
  "ai_category": "编程语言应用"
}
```

### ChromaDB Metadata扩展

```python
{
  "user_id": "...",
  "session_id": "...",
  "triples_json": "[{...}]",
  "triple_categories": "技术,教育,业务"  # 所有分类的汇总
}
```

### 预定义分类列表

- 技术 (technology)
- 业务 (business)
- 教育 (education)
- 医疗 (medical)
- 金融 (finance)
- 人物关系 (person_relation)
- 时间关系 (temporal)
- 其他 (other)
